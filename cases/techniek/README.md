# cases/techniek/ — Technische Cases

Deze map is bedoeld voor technische werkbestanden en cases.

## Wat komt hier?

Tijdens het werken met Claude Code maak je hier submappen aan per project of case. Bijvoorbeeld:

```
cases/techniek/
├── storingsdiagnose/     ← Analyse van storingen
├── rag-documentatie/     ← Documenten doorzoekbaar maken
└── api-integratie/       ← Externe systemen koppelen
```

## Tips

- Maak een submap per case of project
- Voeg een kort `README.md` toe per case met het doel
- Bewaar tussenresultaten hier (niet in de root)
- Gebruik `data/` voor gedeelde datasets

## Aan de slag

Maak je eerste case:
```bash
mkdir cases/techniek/mijn-eerste-case
```

En vraag Claude:
> "Maak een README voor mijn case over [onderwerp]"
