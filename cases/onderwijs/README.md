# cases/onderwijs/ — Onderwijs Cases

Deze map is bedoeld voor onderwijsgerelateerde werkbestanden en cases.

## Wat komt hier?

Tijdens het werken met Claude Code maak je hier submappen aan per project of case. Bijvoorbeeld:

```
cases/onderwijs/
├── feedback-pipeline/    ← Geautomatiseerde feedback
├── rag-curriculum/       ← Curriculum doorzoekbaar maken
└── toetsanalyse/         ← Resultaten analyseren
```

## Tips

- Maak een submap per case of project
- Voeg een kort `README.md` toe per case met het doel
- Bewaar tussenresultaten hier (niet in de root)
- Gebruik `data/` voor gedeelde datasets

## Aan de slag

Maak je eerste case:
```bash
mkdir cases/onderwijs/mijn-eerste-case
```

En vraag Claude:
> "Maak een README voor mijn case over [onderwerp]"
